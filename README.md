Plataforma web interactiva para facilitar el aprendizaje de fundamentos de física, cálculo de vectores y conversiones de unidades
Este proyecto incluye:

Simulador y Calculadora de Vectores:
- Permite ingresar múltiples fuerzas (magnitud en Newtons y ángulo).
- Cálculo automático de componentes en X e Y, magnitud y ángulo de la fuerza resultante mediante teorema de Pitágoras y trigonometría
- Visualización gráfica interactiva en tiempo real usando tecnologías de canvas
Conversor de Sistemas de Medición:
- Conversión dinámica para magnitudes de **Longitud, Masa, Tiempo y Temperatura** (incluyendo fórmulas de conversión avanzadas para Celsius, Fahrenheit y Kelvin)
Módulo Teórico y Multimedia:
- Conceptos fundamentales de física, introducción a vectores y las Leyes de Newton
- Integración de recursos educativos y videos explicativos

Este proyecto fue hecho usando:
- HTML5 para la estructura de las paginas
- CSS3 para los estilos y la interfaz adaptable
- JavaScript (ES6+) para toda la lógica de los cálculos y el DOM
